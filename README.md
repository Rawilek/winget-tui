## 💡 What is winget-tui?

winget-tui is an app that helps you use the Windows Package Manager (winget) more easily. Instead of typing commands, you get a simple menu on your screen. From there, you can search for apps, install new ones, update what you have, or remove apps you no longer want. It works right inside your command prompt or PowerShell window.

If you know how to install software on your computer, but find command lines hard, winget-tui gives you a friendly way to manage programs. It works on Windows 10 and Windows 11.

---

## 📋 Features Included

- Search for Windows apps using an easy menu  
- Install apps with just a few key presses  
- Upgrade all or specific apps quickly  
- Remove apps you don’t need anymore  
- See details about each app before installing  
- Works in your existing Windows Command Prompt or PowerShell  
- Saves time by avoiding typing complex commands  
- Lightweight and fast, no big downloads

## 🎯 How to Use winget-tui 

When you first open winget-tui, you see a menu with a list of options:

- **Search**: Find apps by typing their name or keyword.  
- **Install**: Pick apps from the search results to install.  
- **Upgrade**: See if apps have newer versions and update them.  
- **Manage**: List apps you have installed and remove any.  

Use the arrow keys on your keyboard to move up and down the menu. Press Enter to select an option.

### Searching for Apps

1. Choose “Search” from the main menu.  
2. Type what you want, like “browser.”  
3. Press Enter to see matching apps.  
4. Use arrow keys to scroll the list.  
5. Press Enter on any app to see details or install it.

### Installing Apps

After finding an app:

- Press Enter on the app.  
- Confirm installation when asked.  
- Wait while the app downloads and installs.  

You don’t need to watch the steps, the app will show progress.

### Upgrading Apps

- Select “Upgrade” from the main menu.  
- winget-tui shows which apps have updates.  
- Choose which to update or pick all.  
- The upgrade happens automatically.

### Removing Apps

- Select “Manage” on the main menu.  
- See a list of installed apps.  
- Use arrow keys to pick one to remove.  
- Confirm removal when prompted.

## ⚠️ Troubleshooting Common Issues

- **Winget is not found:**  
  Make sure you have the official Windows Package Manager installed. It should be on Windows 10 version 1809 or newer. You can update it through the Microsoft Store if needed.

- **Apps won’t install:**  
  Check your internet connection. Try running winget-tui as an administrator (right-click the icon and choose “Run as administrator”).

- **Screen layout looks wrong:**  
  Try resizing your Command Prompt or PowerShell window. winget-tui works best in a medium to large terminal window.

- **The app closes immediately:**  
  Make sure you launched winget-tui from Command Prompt or PowerShell and not by double-clicking the executable directly. Alternatively, open a terminal and run the command: `winget-tui`.
